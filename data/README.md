# Источники данных

В каталоге `raw` сохранены неизмененные файлы открыто опубликованного набора СберИндекса Data → Sense: расходы, индекс доступности рынков, население и зарплата Росстата, версионный справочник муниципалитетов.

Первичная публикация: https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim

Справочник: https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities

Фактическое место получения файлов: публичный репозиторий команды хакатона 2025 года `TrueSpearmint/sberindex_hackathon`, commit `2688b801792b7d43e4f460d7004bccac374960d2`. Использованы только файлы исходных данных. Их авторство не приписывается этому проекту. Первичные права и условия использования данных определяет их правообладатель; лицензия исходного аналитического кода не заменяет условия источника.

Подробные адреса каждого файла, размер, SHA-256 и Git blob SHA находятся в `sources.json`. Загрузчик не принимает файл с измененной контрольной суммой. Совпадение полученной копии с текущим официальным архивом не проверено из-за недоступности сервера первоисточника.

В `results/panel.parquet` находится производная сбалансированная панель, а в `results/excluded_municipalities.csv` — исключенные МО. Исходные файлы не редактируются.
