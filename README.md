# Потребительские профили муниципалитетов

Динамическая кластеризация 2 016 муниципальных образований по данным СберИндекса за 2023–2024 годы. Для каждого месяца строится взвешенная сеть экономического сходства. Пять типов сравниваются по составу расходов, динамике, зарплате, населению и доступности рынков.

## Воспроизведение

Проверено на Python 3.12. Все команды выполняются из корня репозитория.

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell вместо предыдущей строки:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python download_data.py
python run.py --config configs/default.yaml
python analyze_results.py
python build_report.py
python -m pytest -q
```

`download_data.py` проверяет уже вложенные исходные файлы по SHA-256. Интернет нужен только для установки зависимостей или восстановления отсутствующего файла. Для точного повторения окружения доступен `requirements-lock.txt`. Расчет выполняется на CPU. Параметры и seed находятся в `configs/default.yaml`, использованная конфигурация — в `results/config_used.yaml`. Для нового набора данных нужно обновить снимок и его описание, повторить расчеты и заново проверить содержательные названия типов в `configs/types.yaml`.

Основная модель — `graph_temporal`: компактность групп по атрибутам, штраф за разрез сильных связей и штраф за смену типа. Для сравнения реализованы K-means, Ward и спектральная кластеризация. K выбирается на трех срезах первого полугодия 2023 года. Таблица сравнения содержит средние метрики за июль 2023 — декабрь 2024 при одном K.

## Состав репозитория

```text
municipal/         подготовка данных, сеть, кластеризация, метрики
configs/           гиперпараметры и названия типов
data/raw/          исходные файлы
data/sources.json  происхождение, версия и SHA-256
results/           рассчитанные таблицы и ежемесячные сети
reports/           отчет, презентация, графики
tests/             проверки данных и математических свойств методов
run.py             полный расчет
analyze_results.py портреты и проверки административных версий
build_report.py    сборка PDF, графиков и интерактивного просмотра
download_data.py   восстановление исходных файлов
```

Сети сохранены в формате SciPy CSR (`scipy.sparse.load_npz`). Порядок узлов указан в `results/municipalities.csv`. Метки начинаются с 1. Номера согласованы по пересечению групп соседних месяцев. Исходный `territory_id` остается ключом для соединения таблиц.

## Данные и трактовка

Источник расходов, доступности рынков и справочника — [СберИндекс](https://sberindex.ru/ru/research/data-sense-opisanie-nabora-dannikh-khakatona-sberindeksa-po-munitsipalnim-dannim). Зарплата и население — данные Росстата из того же набора. Файлы получены из публичной копии материалов хакатона 2025 года; точные ссылки указаны в [описании снимка](data/sources.json). Текущий официальный архив во время загрузки был недоступен, поэтому совпадение с его нынешней версией не проверено.

Кластеры описывают потребительские профили. Ребра означают сходство, а не реальные потоки денег. Результаты относятся к сбалансированной панели. Зарплата, население и доступность рынков служат внешними характеристиками и не участвуют в обучении. Описание ограничений и соглашений по метрикам находится в отчете.
